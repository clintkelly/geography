## General knowledge only, not looked up

- **Capitals:** Canberra, Wellington, Port Moresby, Honiara, Apia, Majuro. Several appear in the capital lists found above, but they were not checked one by one.
- **Largest cities:** Auckland, Port Moresby, Honiara, Port Vila, Apia and Majuro.
- **All same-place city lists** except the places named above. Tarawa, Funafuti, Majuro and Apia as largest are general knowledge too.
- **Hints:** "Y-shaped" Vanuatu, "more than 300" Fiji islands (a search found 322 to 330+), "two big" Samoan islands, "hundreds" of Palau islands, the two Marshall chains, the four Micronesian states.
- **All remaining neighbor links.** Australia, New Zealand, Papua New Guinea, Solomon Islands, Vanuatu, Samoa and Tonga links are usual flights from general knowledge. Kiribati to Tuvalu and Palau to Micronesia are sea neighbors, not known direct flights. Yap and Palau are each served from Guam, and Yap's stone money came from Palau by sea.
- **`tiny` flags** come from map bounding boxes at 960px plus judgment. Fiji and the Solomon Islands are thin island chains, so they are marked tiny despite wide boxes.

## For the owner to decide

- **Nauru's capital.** The generated questions will say "Yaren is the capital of Nauru", while the Field Note and clue say it has no official capital. A careful child may notice. `hint2` and one fact tell the truth; the question template can't.
- **Nauru's "cities".** Denigomodu, Meneng and Aiwo are districts, and the game will call them cities. Monaco and San Marino have the same issue.
- **Island towns as "cities".** The same applies to Kiritimati, Abemama, Butaritari, Vaitupu, Nanumea, Nui, Jaluit, Wotje and Peleliu, which the rules allow.
- **Kiribati label.** The file says Tarawa. Some quizzes expect South Tarawa, and some sources name Bairiki.
- **Sydney or Melbourne.** The game will say Sydney is the largest. That is true on one ABS measure and false on another. Both are offered as answers.
- **Micronesia.** The name is also the wider region, which includes Palau, Nauru, Kiribati and the Marshall Islands. `wiki` is set to `Federated_States_of_Micronesia` so sources link to the country. The hints in this file avoid the word.
- **Jellyfish Lake** has closed before when the jellyfish declined, so it may not always be open to visitors. The fact stays true either way.
- **Tuvalu** has no feature in world-atlas, so it needs the `tiny` dot from `lonLat`. It keeps ISO 798, and any code that looks up the feature by id must cope with that.
- **Australia's id.** ISO 036 is shared in world-atlas by Australia and Ashmore and Cartier Is., so `036` matches two features. Any code keyed on feature id, such as a React key, should allow for that.
- **Left out on purpose:** the Kennedy PT-109 story and Bikini Atoll (war), and the Tuvalu sea-level story, which is a heavy topic for this age. The owner may want it as a later, gentler fact.
